# Digital Bank Landing Page 💳📱

A modern and responsive landing page for a digital banking application.
This project is built using **HTML & CSS** and follows clean layout and
responsive design principles.

---

## 🔥 Features

- Responsive hero section
- Full-width mobile app illustration
- Clean and modern UI
- Max-width container layout (1280px)
- Google Fonts (DM Sans)
- Beginner-friendly project structure

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Google Fonts (DM Sans)
- Flexbox & Positioning
